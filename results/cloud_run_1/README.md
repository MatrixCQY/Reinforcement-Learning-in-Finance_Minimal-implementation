# cloud_run_1

默认配置（`config.Param()`）训练 1 个 episode（训练集 4646 个交易日），随后在测试集（1162 个交易日）评估。
CPU 训练，约 5 分钟。

- `*_episode0.csv`：训练记录
- `*_Eval_episode0.csv`：测试集评估记录（`buy_hold` 列为基准）
- `PPO_*_0.pth`：模型
- `*.html`：`dataAnalysis.py` 生成的图表

## 结果（测试集）

| 方式 | 收益 |
|---|---|
| 买入持有（初始 10 万现金 + 5000 股） | +13.37% |
| 确定性策略（argmax） | +13.37%（1151 步全部选 0=持有，等同买入持有） |
| 按概率采样，5 个随机种子 | 26.3 / 14.9 / 4.2 / 27.1 / 8.4 %，均值 16.2% |

策略输出熵 2.72（均匀分布为 3.04），训练 1 个 episode 后仍接近随机；采样结果方差大，5 次样本不足以说明优于基准。
